Use este link em páginas externas ao painel

Instale o script abaixo em qualquer página (landing page, site institucional) para rastrear visitas e cliques no botão do WhatsApp com a mesma atribuição deste link.

Se preenchido, o script escreve este texto automaticamente no(s) botão(ões) do site ao carregar a página — sem precisar editar o HTML/JSX. Deixe vazio para manter o texto que já está escrito no botão do site.

O script intercepta o clique nesse botão e abre o WhatsApp com a mensagem do link. Para uma mensagem diferente por botão, use o atributo data-wapp-message. Se o botão tiver ícone, marque o texto com data-wapptrack-label para o texto configurado acima trocar só o texto, preservando o ícone.

Separe por vírgula. Deixe vazio para permitir qualquer domínio. Recomendado para evitar uso indevido do script em sites não autorizados.
